# Assets

This folder stores lightweight supporting files used in project documentation, README files, project logs, and notes.

Use this folder for:

- Screenshots
- Diagrams
- Documentation images
- Project-log images
- Reference figures
- Small visual examples

Do not use this folder for primary research data, large generated outputs, or final dissertation figures.

Generated analysis products should usually go in [`outputs/`](../outputs/).
Raw or processed datasets should go in [`data/`](../data/).
GIS files should go in [`gis/`](../gis/).
